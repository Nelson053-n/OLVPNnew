# План: Автоматическая проверка оплаты (фоновый polling)

## Контекст

Сейчас проверка оплаты — только ручная: пользователь нажимает кнопку "🔎 Проверить оплату". Если пользователь заплатил, но не нажал кнопку — ключ не будет сгенерирован.

Нужно: после создания платежа запускать фоновую задачу (asyncio.create_task), которая каждые 10-15 секунд проверяет статус в YooKassa. При успехе — автоматически генерирует ключ и уведомляет пользователя. Таймаут — 10 минут. Кнопка ручной проверки остаётся.

## Подход

1. При создании платежа (`build_pay.py`) запускать `asyncio.create_task` с polling-функцией
2. Polling-функция живёт в `after_pay_handler.py` — там уже вся логика after_pay
3. Задача polling хранится в FSMContext (payment_id → task), чтобы:
   - Не дублировать задачи при повторных нажатиях на тарифы
   - Отменять при ручной проверке (кнопка)
   - Отменять при нажатии "Назад"
4. При успешной ручной проверке — отменять фоновую задачу (если ещё бежит)

## Файлы для модификации

| Файл | Изменение |
|------|-----------|
| `core/handlers/handlers_keyboards/after_pay_handler.py` | Добавить `start_payment_polling()` и `_poll_payment_status()` |
| `core/utils/build_pay.py` | После создания платежа — запускать polling |
| `core/handlers/handler_keyboard.py` | При "back" — отменять polling-задачу |

## Реализация

### after_pay_handler.py — новая функция polling

```python
async def _poll_payment_status(bot, user_id, payment_id, payment_date, state_data):
    """Фоновый polling YooKassa каждые 12 секунд, таймаут 10 минут."""
    for _ in range(50):  # 50 * 12с = 10 минут
        await asyncio.sleep(12)
        try:
            if await check_payment(payment_id):
                # Оплата прошла — генерируем ключ и уведомляем
                ...создаём ключ через get_ol_key_func-подобную логику...
                ...отправляем сообщение пользователю через bot.send_message...
                return
        except Exception:
            continue  # Ошибка API — пробуем снова
```

### build_pay.py — запуск задачи

После `await state.update_data(pay=...)` запускаем polling-задачу, сохраняя её в dict по user_id чтобы можно было отменить.

### handler_keyboard.py — отмена при "back"

При обработке callback "back"/"back_start" — отменять polling если есть.

## Верификация

- Создать платёж, подождать — ключ должен прийти автоматически
- Создать платёж, нажать кнопку вручную — ключ через кнопку, polling отменяется
- Создать платёж, нажать "Назад" — polling отменяется
- Не оплачивать — через 10 минут polling прекращается без ошибок
