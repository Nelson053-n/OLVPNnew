#### 1.1 Рефакторинг `RotatingFileLogger`

**Добавить функциональность:**
```python
class RotatingFileLogger:
    # Существующее:
    - setup_logging()
    - handle_exception()
    - log()
    
    # Новое:
    + cleanup_old_logs(days: int) -> int  # Удаление старых логов
    + compress_old_logs(days: int) -> int  # Сжатие в gzip
    + get_log_files() -> List[Path]  # Список файлов

    + get_logs_size_mb() -> float  # Размер в MB
```

```json

    "max_bytes": 200000000,
    "backup_count": 7,
    "use_compression": false,
    "log_name": null
}
```

#### 1.2 Утилита для очистки логов

**Файл:** `cleanup_logs.py`


**Функционал:**
- Удаление логов старше N дней
