Telegram-бот для удобной покупки и управления ключами Outline VPN.

### Локальный запуск
```bash
git clone https://github.com/Nelson053-n/OneYearVpb.git
cd OneYearVpb
pip install -r requirements.txt
# Заполните .env параметры
python main.py
```

```bash

sudo systemctl start olvpn-support-bot
```

## 📋 Основные команды

### Для пользователей
- `/start` - Главное меню, просмотр активных ключей, покупка доступа

### Для администраторов

**Программа лояльности:**
- `/promo` - Выдать промо-ключи (7 дней) пользователям без активных ключей

**Управление ключами:**
- `/keyinfo <user_id>` - Информация о ключах, блокировка по необходимости
- `/activekeys` - Список активных пользователей
- `/massblock` - Блокировка всех просроченных ключей

**Серверы:**
- `/addserver` - Добавить новый Outline сервер
- `/deleteserver` - Удалить сервер
- `/serverstats` - Статистика нагрузки серверов
- `/migrateserver <from> <to>` - Перенести пользователей между серверами

**Другое:**
- `/editprice` - Изменить цены (день/неделя/месяц)
- `/findpay <user_id>` - Найти платежи пользователя
- `/seed` - Создать тестовых пользователей
- `/unseed` - Удалить тестовых пользователей
- `/get_db` - Скачать базу данных
- `/get_log_pay` - Скачать логи платежей

**Полный список команд:** см. [DOCS.md](DOCS.md#-команды-администратора)

## Команды

### Команды для пользователей

- `/start` - Запуск бота и главное меню

### Команды для администраторов

#### Управление пользователями и ключами

- `/findpay <user_id>` - Поиск успешных платежей конкретного пользователя в YooKassa
- `/keyinfo <user_id>` - Просмотр информации о ключах пользователя (трафик, регион, статус) с возможностью блокировки
- `/activekeys` - Список всех пользователей с активными ключами и датами окончания
- `/massblock` - Ручная проверка и блокировка всех просроченных ключей
  - Выводит количество заблокированных ключей
  - Если просроченных ключей нет, выводит: "Просроченные ключи не найдены"

#### Миграция со старой версии бота

- `/checkstatus` - Проверка статуса миграции ключей
  - Показывает сколько пользователей уже мигрировано
  - Сколько требуют миграции
  - Общее количество пользователей

- `/migrate` - **Автоматическая миграция старых ключей** в новую систему
  - Переносит ключи из поля `Users.key` в таблицу `UserKey`
  - Сохраняет все параметры: дату, премиум-статус, регион
  - Проверяет наличие ключа на Outline сервере
  - НЕ удаляет старые данные (для безопасности)
  - Пропускает уже мигрированных пользователей
  - **Подробнее:** См. [MIGRATION_GUIDE.md](MIGRATION_GUIDE.md)

#### Промо-ключи

- `/promo` - Показывает список пользователей БЕЗ платных активных ключей
  - Для каждого пользователя отображается кнопка "🎁 Промо"
  - При нажатии создается промо-ключ на **7 дней**
  - Пользователю отправляется уведомление о получении промо-ключа
  - Если у пользователя есть платный активный ключ, он не показывается в списке

#### Тестовые данные

- `/seed` - Создание тестового пользователя для отладки
  - Создается пользователь с ID и именем `test_XXXXX` (5 случайных символов)
  - Добавляется 2 ключа:
    - **Просроченный** (истёк вчера)
    - **Активный** (истекает через 1-3 часа)
  - Создается тестовый платёж в БД
  - Ключи создаются на **реальном Outline сервере**
  - Платёж НЕ проходит через YooKassa API

- `/unseed` - Удаление всех тестовых данных
  - Удаляет всех пользователей с именами `test_*`
  - Блокирует и удаляет их ключи с Outline серверов
  - Удаляет записи о платежах
  - Полностью очищает БД от тестовых пользователей

#### Управление серверами

- `/addserver` - Добавление нового Outline сервера (интерактивный процесс)
  - **Шаг 1:** Ввод названия страны на английском (например: `germany`, `france`, `usa`)
  - **Шаг 2:** Ввод API URL сервера (например: `https://123.456.789.012:12345/aBcDeFgH`)
  - **Шаг 3:** Ввод SHA256 сертификата (64-символьная строка)
  - Автоматически добавляет флаг страны 🇩🇪🇫🇷🇺🇸
  - Сохраняет конфигурацию в `settings_api_outline.json`
  - Сервер активируется после перезапуска бота
  - Команда `/cancel` - отмена добавления на любом этапе

#### Логи и база данных

- `/get_log_pay` - Получить файл с логами платежей
- `/get_db` - Получить файл базы данных SQLite

## Требования

Для запуска проекта вам потребуется следующее:

- Python 3.9 или выше
- aiogram для работы с Telegram API
- SQLAlchemy для работы с базой данных
- asyncpg для асинхронного взаимодействия с PostgreSQL
- Jinja2 для шаблонизации сообщений
- urllib3 для выполнения HTTP-запросов
- python-dotenv для управления переменными окружения
- var-dump для отладки
- yookassa для обработки платежей через YooKassa

## Установка и Использование

0. Будем считать, что токен TLG, Outline сервер а так же данные для платежей в ЮКасса у Вас уже есть.
1. Клонируйте репозиторий на свой компьютер/сервер.
2. Создайте виртуальное окружение и активируйте его.
3. Установите зависимости с помощью команды `pip install -r requirements.txt`.
4. При запуске введите запрашиваемые данные или отредактируйте файл `.env`, чтобы настроить бота под свои нужды.
5. Запустите бота с помощью команды `python main.py`.

### Автоматизация запуска бота (Ubuntu/systemd)

Все действия из консоли, поменяйте данные на свои по необходимости

```bash
nano /etc/systemd/system/olvpnbot.service
```

```ini
[Unit]
Description=Opnbot
After=network.target

[Service]
Type=simple
User=root
Group=root
Restart=on-failure
WorkingDirectory=/root/tlg/bots/olvpnbot
ExecStart=/root/tlg/bots/olvpnbot/venv/bin/python3 /root/tlg/bots/olvpnbot/main.py

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl start olvpnbot
systemctl status olvpnbot
systemctl enable olvpnbot
```
